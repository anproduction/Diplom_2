# Тесты API для Stellar Burgers

Этот проект содержит автоматические тесты для API сервиса **Stellar Burgers** — популярного конструктора бургеров.

## Содержание

- Тесты регистрации пользователей
- Тесты авторизации
- Тесты создания заказов
- Генерация отчётов Allure
- Проверка покрытия кода (для юнит-тестов)

---

## Структура проекта

```bash
.
├── conftest.py           # Фикстуры для тестов
├── endpoints.py          # Список всех API эндпоинтов
├── test_data.py          # Валидные и невалидные ID ингредиентов
├── test_user.py          # Тесты регистрации пользователя
├── test_auth.py          # Тесты логина
├── test_orders.py        # Тесты создания заказов
├── requirements.txt      # Зависимости
├── README.md             # Документация проекта

## Установка

Установите зависимости:

``` pip install -r requirements.txt ```

## Запуск тестов

``` pytest -v ```
